# Permanent Sidebar Modern Admin UI

This folder contains one fresh full-page desktop screenshot for each of the 17 authenticated admin routes after the permanent-sidebar and shared-component modernization.

Every capture verified that:

- the desktop sidebar is 268 pixels wide;
- the full business name and navigation labels are visible;
- no desktop expand or collapse control exists; and
- the page finished rendering before capture.

The existing mobile navigation drawer was separately checked at a 390 × 844 viewport. It keeps the full logo, business name, and labels when open and does not introduce document-level horizontal overflow.

The screenshots use the local synthetic-development session. No forms were submitted and no records were changed. This is local browser evidence, not physical-device, production, assistive-technology, or client-acceptance evidence.
