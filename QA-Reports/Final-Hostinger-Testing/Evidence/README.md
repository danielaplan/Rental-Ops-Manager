# Final Hostinger Testing Evidence

Save screenshots for every **FAIL** or **BLOCKED** result in this folder. Do not include passwords, session tokens, real customer data, browser address-bar credentials, or database details.

Use this filename format:

```text
HST-F<scenario>-<YYYYMMDD>-<short-description>-<number>.png
```

Examples:

```text
HST-F04-20261027-conflict-approved-without-reason-01.png
HST-F12-20261027-offline-payment-duplicated-after-sync-01.png
```

Reference the filename in [Report.md](../Report.md). Do not paste screenshots inside the report; keeping them here works in GitHub, VS Code, and Obsidian after the files are committed.
