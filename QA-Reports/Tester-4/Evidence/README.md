# Tester 4 Screenshot Evidence

Save every Tester 4 screenshot in this folder. Do not paste or link screenshots inside `Report.md`; the filename connects each image to its scenario and bug.

## Required filename

For an application bug:

```text
T4-S<scenario>-BUG-<number>-<short-description>-<image-number>.png
```

Example: `T4-S31-BUG-01-checklist-duplicated-01.png`

For a blocker without an application Bug ID:

```text
T4-S<scenario>-BLOCKED-<short-description>-<image-number>.png
```

Example: `T4-S31-BLOCKED-mysql-unavailable-01.png`

Use `-01`, `-02`, and so on when one problem needs multiple screenshots. Use lowercase words separated by hyphens, keep the original image format (`.png`, `.jpg`, or `.webp`), and never include passwords, tokens, or real customer information.
